# 结构插槽（structures/）

> **这里放"幕怎么排"，不放"讲什么"。**
> 本包默认结构是 `seven-act.md`（七幕升维）。换成别的题材时，不需要改任何脚本，也不需要改 `references/`——
> 只需要在这里挑一个结构，或者照 `_template.md` 自己写一个。

---

## 1. 这个目录解决什么问题

七幕升维对"**一个人被麻烦逼到墙角，然后造出了一个原本不存在的东西**"这类题材近乎最优。
但如果你的选题是"一个制度怎么烂掉""两个学派吵了一百年""一座城怎么被放弃"，硬套七幕会得到两种坏结果：

| 硬套的症状 | 根因 |
|---|---|
| 第 3 幕"动手"编不出东西，只能写"让我们来看看" | 选题里没有"跟着做一步"这个动作 |
| 第 4 幕"造物"找不到兑现物，只好堆知识点 | 选题里根本没有"造出来的东西" |

结构不对，画面再精致也救不回来。所以结构必须是**可选参数**，不是刻在石板上的规定。

---

## 2. 怎么用（三步）

| 步 | 动作 | 产物 |
|---|---|---|
| 1 | 读本目录下各结构的 `适合 / 不适合`，选一个 | 结构 id（默认 `seven-act`） |
| 2 | 把该结构文件的**幕表**整表抄进 `templates/脚本骨架.template.md` §三，替换原有行 | 本集的幕表 |
| 3 | 写脚本时，凡本包其它文档提到"七幕/奇景/困局/造物/升维"，按 §3 的映射理解 | 不产生歧义 |

**只改这三处。** `references/` 下的方法论、判据、`scripts/` 下全部脚本都不需要动
（脚本不依赖幕数或幕名，只查字幕、音频、画质这类格式项——已实测确认）。

---

## 3. 映射规则：其它文档里的七幕字样怎么读

本包 `references/` 与模板以默认结构（七幕）举例。换成别的结构时按下表替换，**不要照字面理解**：

| 文档里写 | 换成别的结构时读作 |
|---|---|
| 奇景 | **钩子幕**（第 1 幕，任何结构都不变） |
| 困局 | **冲突幕**（缺口被撕开的那一幕） |
| 动手 | 若结构有"参与/共做"幕则保留；没有就**删掉该要求**，不要硬加 |
| 造物 | **兑现幕**（结构文件里 `兑现幕` 字段指定的那一幕） |
| 穿透 | **外延幕**（兑现之后讲"它还影响了什么"）；结构无此幕则删掉该要求 |
| 升维 | **落点幕**（结构文件里 `落点幕` 字段指定的那一幕） |
| 追问 | **收尾幕**（最后一幕，任何结构都不变） |
| 「第 4 幕必须最长」 | 「**兑现幕必须最长**」——这是不变量，不是七幕专属 |

> 换句话说：**头（钩子）和尾（收尾）是固定件，中间 3–5 幕是插拔件。**

---

## 4. 不变量：换任何结构都不能丢的 8 条

这些跟"幕怎么排"无关。丢了它们，结构换得再对，完播率也会掉——因为丢掉的是方法，不是排版。

| # | 不变量 | 判据 / 去处 |
|---|---|---|
| 1 | **片头 ≤1.0s**，含全部品牌元素（做系列时） | `epcheck.py` CK-10 / 人工 |
| 2 | **开场 8 秒零前置知识**，且按六句范式写 | R1 §6 + `qc27_hooks.py` |
| 3 | **片头结束后 3 秒内亮赌注**（系列=给 A/B 记分；单条=一条将被验证的断言） | R1 §7 |
| 4 | **钩子间隔 ≤25 秒**（全片无 25s 空窗） | `qc27_hooks.py`，超了直接 FAIL |
| 5 | **兑现幕必须是全片最长的一幕** | 逐幕时长表；短了说明钱花在包装上 |
| 6 | **落点幕必须给出可迁移的思维动作，不是本集总结** | QC-16；把该句单独拎出来读 |
| 7 | **字幕单条 ≤22 字、停留 ≤4.5s** | `qc28_subpacing.py` |
| 8 | **不承接上一集开场**（不写"上一集我们说到"） | 人工，红线第 13 条 |

> 第 5、6 条过去写成"第 4 幕""第 6 幕"，那是七幕的说法。**结构一变，幕号就失效，所以必须改说"兑现幕/落点幕"**——
> 这就是为什么结构文件要显式声明这两个字段。

---

## 5. 一个结构文件必须填的 6 个槽

照 `_template.md` 填，缺一项这个结构就不成立（多半是套模板套出来的，不是真能生产）：

| 槽 | 填什么 | 为什么必须有 |
|---|---|---|
| `id` / 名称 | 唯一短名 | 被 SKILL.md 和骨架模板引用 |
| `幕数 + 总时长` | 各幕时长区间，**合计等于声明的总时长** | 时长预算从这里分配 |
| `兑现幕` | 哪一幕兑现了开场悬念 | 不变量 5 靠它判 |
| `落点幕` | 哪一幕给出可迁移的思维动作 | 不变量 6 靠它判 |
| `适合` | 什么样的选题用它 | 路由依据 |
| `不适合` | **什么样的选题别用它**（比"适合"更重要） | 没有这条，AI 会什么都往里塞 |
