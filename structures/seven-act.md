# 结构 · 七幕升维（`seven-act`）

> **本包默认结构，已生产验证。**
> 一句话内核：**一个人被什么麻烦逼到墙角，然后造出了一个原本不存在的东西。**
> 这个文件只定义"幕怎么排"；所有结构都必须满足的不变量见 `structures/README.md` §4。

---

## 1. 元数据

| 槽 | 值 |
|---|---|
| `id` | `seven-act` |
| 幕数 | 片头 + 7 幕（共 8 段） |
| 总时长 | **182–276s（3–4.5 分钟）** |
| 钩子幕 | 1 · 奇景 |
| **兑现幕** | **4 · 造物** ← 全片必须最长 |
| 落点幕 | 6 · 升维 |
| 收尾幕 | 7 · 追问 |
| **适合** | 有"麻烦 → 造物"完整因果链的题材：发明、发现、制度设计、技术原理、一次攻关、一个人的关键选择 |
| **不适合** | ① 没有"造物"的题材（观点对峙、学派之争）→ 中段会空<br>② 结局是"崩掉"而不是"造出来"的题材（制度瓦解、公司衰亡）→ 第 4 幕无法兑现<br>③ 纯抽象概念解释（无穷、概率）→ 优先试 `思想实验` 变体，仍不行则换结构 |

> 判断标准很简单：**如果第 4 幕你说不出"造出来的那个东西长什么样"，这个结构就不适合这个选题。**

## 2. 幕表

| 幕 | 名称 | 时长 | 硬要求 |
|---|---|---|---|
| 0 | 片头 | **≤1.0s** | 品牌元素一个不少（logo + 系列名 + 口号 + 集数主题 + 右上角集标）；**同起片头 BGM**；0.12s「唰」飞入 |
| 1 | **奇景** | 12–20s | **片头结束后前 3 秒抛赌注**（R1 §7）；一个可看见的具体物**并带数量**；一句断言不给结论；**开场按 R1 §6 六句范式写** |
| 2 | **困局** | 30–45s | **4–8 个镜头**，含 1 个道具锚；★ 必须出分镜板 |
| 3 | **动手** | 22–32s | "跟着我算 / 跟着我做"，**10 秒内能完成一步** |
| 4 | **造物** | 45–70s | ★ 全集最重要的动画段；≥1 个"画面自解释"演示（不看旁白也懂） |
| 5 | **穿透** | 35–50s | 领域跨越链条，举例具体到人物与年份，**≥1 个非西方例子**（选题允许时） |
| 6 | **升维** | 25–40s | 收束为单一意象 + 锚点大字；**末尾留白 1.5s 全静音** |
| 7 | **追问** | 12–18s | 下集预告 + 赌注对账 + 关键词铭牌；预告帧 = 下集奇景首帧 |

**合计 182–276s（3–4.5 分钟）。**

## 3. 每幕的一句话职责

写脚本时逐幕自问：**这一幕结束时，观众脑子里多了一个什么问题？**

| 幕 | 观众此刻的问题 | 如果这一幕删掉 |
|---|---|---|
| 奇景 | "这有什么稀奇？" | 没有悬念，后面全是灌输 |
| 困局 | "那怎么办？" | 造物没有价值（不痛就不需要解药） |
| 动手 | "我好像也能做" | 观众从旁观者变不进来 |
| 造物 | "原来是这样！" | 全片没有兑现时刻 |
| 穿透 | "影响这么大？" | 观众觉得"跟我没关系" |
| 升维 | "我可以这样看世界" | 不收藏、不转发 |
| 追问 | "下一集呢？" | 单条完播可以，系列追更起不来 |

**第三列是这张表的真正用法**：写完之后逐幕"删掉试试"，看哪一幕删了最痛。
如果某一幕删掉毫无损失，那一幕就是注水，不管它名字多好听。

## 4. 时长纪律

- **兑现幕（4 · 造物）必须是全片最长的一幕。** 它短了，说明你把钱花在了包装上而不是兑现上。
- **钩子幕（1 · 奇景）不要超过 20s。** 前 20 秒还没进入"麻烦"，人就走了。
- **落点幕（6 · 升维）宁可短，不要注水。** 一句话能说完的，不要写三句。
- 各幕区间之和必须落在 182–276s 内；**超出就砍情节，不要压缩兑现幕**。

## 5. 中段变体（本结构内部，不是换结构）

七幕的**中段**（幕 2–5）可以按题材换排法，头尾不动。这四种变体仍然属于 `seven-act`：

| 变体 | 中段骨架 | 适合的题材 |
|---|---|---|
| **W · 七幕升维**（主） | 一个人 → 一个麻烦 → 一件造物 | 默认，80% 的选题 |
| **A · 双线对撞** | 两条线并行推进，在中段撞上 | 有竞争、有路线之争、有"同时发现" |
| **B · 思想实验** | 先给一个假设情境，让观众跟着推理 | 抽象概念（无穷、概率、因果、时间） |
| **C · 物的传记** | 以一件物为主角，跟着它穿越时代 | 器物、符号、工具、制度 |

**轮换纪律**：同一变体连续使用 **≤3 集**。第 4 集必须换。
做单条视频时，按题材选最合适的；做系列时，变体本身要排班。

> 变体 B（思想实验）会让第 3 幕"动手"退化为"跟着推一步"，这是允许的——
> 它仍在兑现幕之前建立"我好像也能参与"，职责没变。

## 6. 落点幕：升维 7 型

| 型 | 做什么 | 抽象示意 |
|---|---|---|
| ① 尺度 | 从局部拉到极大/极小 | 从一滴水拉到整个水循环 |
| ② 视角 | 换一个观察者的位置 | 从"人看地图"换成"地图看人" |
| ③ 时间 | 拉到百年/千年尺度 | 一个今天习以为常的设计，在两百年后变成什么 |
| ④ 概念 | 把这个具体问题抽象成一类问题 | 从"这次分不均"到"所有分配问题" |
| ⑤ 身份 | 换一个主体（不是人） | 从"人怎么适应环境"到"环境怎么筛选人" |
| ⑥ 反身 | 把方法用回它自己 | 用这套推理去检验这套推理 |
| ⑦ 文明 | 落到文明尺度 | 一个技术如何改变了一个文明的走向 |

**纪律**：

- 每集**试 ≥3 型**，选**最不像"总结"**的那个。
- **同型连续两集不重复。**
- **⑦ 文明型每季 ≤1 次**（用多了像宏大叙事，观众免疫）。

**QC-16 判据**：把落点句单独拎出来读。**若只是本集内容总结 → 不合格。**

- 好例子："这不是他聪明，是他把'不知道'当成了一个可以计算的东西。"
- 坏例子："所以，这个故事告诉我们，坚持就会成功。"

> **换结构时这一段怎么处理**：落点幕换了位置、换了性质（比如"余波"而不是"升维"），
> 7 型表仍然可用作**备选角度清单**，但 QC-16 的判据必须跟着改——
> 判据永远是"**这句话有没有给出一个能带走的东西，而不是复述本集内容**"。

---

## 7. 本结构的红线（结构层面，与全局红线并列）

1. **兑现幕不得被砍时长来给其它幕腾预算。**
2. **钩子幕不许承接上一集开场**（全局红线 13 在此的落地）。
3. **落点幕不得变成内容总结**（QC-16）。
4. **收尾幕的预告帧必须等于下一集钩子幕的首帧**——否则观众会感到"跳戏"（做系列时）。
5. **穿透幕举的例子必须具体到人物与年份**，不许写"后来被广泛应用"。
