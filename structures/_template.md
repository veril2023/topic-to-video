## 5. 填法示例：`collapse`（制度 / 组织 / 理论的崩解）

> ⚠️ **下面这个示例没有经过真实生产验证**，只示范"槽怎么填"。
> 拿它做片之前请自己试一集，试成了再把它独立成 `structures/collapse.md` 并标注状态。

| 槽 | 值 |
|---|---|
| `id` | `collapse` |
| 幕数 | 片头 + 6 幕 |
| 总时长 | 190–260s |
| 钩子幕 | 1 · 常态 |
| **兑现幕** | **4 · 崩塌** ← 必须最长 |
| 落点幕 | 6 · 余波 |
| 收尾幕 | 6 · 余波（与落点幕合并） |
| **适合** | 制度瓦解、公司衰亡、理论被推翻、共识破裂——"曾经很稳的东西怎么没了" |
| **不适合** | 需要给出建设性方案的题材（这个结构只解释怎么坏的，不给解药） |

幕表：

| 幕 | 名称 | 时长 | 硬要求 |
|---|---|---|---|
| 0 | 片头 | ≤1.0s | 同默认 |
| 1 | **常态** | 15–25s | 一个"当时所有人都觉得理所当然"的具体场景 + 一个数字 |
| 2 | **裂缝** | 30–45s | 一个当时被当成小毛病、后来致命的细节 |
| 3 | **第一次失效** | 25–40s | 有人试图补救，失败；把"补不上了"这件事演出来 |
| 4 | **崩塌** | 50–75s | ★ 最长；崩塌的**机制**要能一眼看懂（不是"然后就崩了"） |
| 5 | **谁受益** | 25–35s | 崩塌从来不是全输；给出至少一个从中获利的具体角色 |
| 6 | **余波** | 25–40s | 今天还在承受什么 → 可迁移的判断动作（不是"以史为鉴"） |

合计 190–260s。

**注意这个示例做了什么改动**：兑现幕从"造物"变成"崩塌"，落点幕与收尾幕合并（省一幕），
新增了"谁受益"——**而头（钩子）和尾（一句没答案的问题）没动**。这就是插槽该有的样子：
**头尾不动，中段按题材重排。**
