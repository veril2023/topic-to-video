## 10. 标准流程（15 步）

1. 选题分析（体检表）→ QC-0
2. 观众/平台确认
3. 单集目标定义（**先写结尾那句，再写开头**）
4. 大纲（七幕 + 变体）
5. 查重 → QC-1
6. **a** 检索稿 + `FACTS.md` → **QC-20**；**b** 改写稿 → QC-2
7. **开场三件套**（v6 新增，成本最低的完播率杠杆，必须在这一步做完）：
   - **开场钩子**按 §3.4 ep03 范式写，前 8 秒零前置知识 → 自查六条硬指标
   - **母题赌注句**按 §3.5 写在片头后 3 秒，自带钩子属性 → 对照 `SERIES.md` 记分牌
   - **拆字幕**：任何一句 >22 字或预计 >4.5s，在这一步就拆成两 cue
   - → **QC-27 / QC-28**（**在写 HTML 之前跑**，此时改字零成本；渲染后发现必然重录重渲）
8. **分镜设计 → 分镜板 SVG** → **QC-17**
9. 素材预处理（照片 + AI 生成 + 后处理）→ QC-15/18
10. 音频构建（三层声轨 + **片头 BGM 第四层**）→ QC-3/5
11. HTML 动画（句级驱动）→ QC-4/11/13
12. probe → 全量渲染 → 编码
13. 质检门全跑 → **QC-0~28**
14. **逐帧验收（QC-21）+ 通俗化门（QC-22）+ 空画面门（QC-23）+ 重叠门（QC-24）+ 压字门（QC-26）**
15. 交付 + 复盘回写

### 渲染命令模板

```bash
NODE_PATH="C:/Users/Administrator/.workbuddy/binaries/node/workspace/node_modules" \
  "C:/Users/Administrator/.workbuddy/binaries/node/versions/22.22.2-6/node.exe" render_ep01.js probe 0.8 6 20 40 120 200
# 全量
NODE_PATH=... node render_ep01.js
# 编码（定稿参数：crf18 / L4.2 / 不加 -shortest / ★必须收敛 colour range）
ffmpeg -y -framerate 24 -start_number 0 -i frames_ep0N/frame_%06d.jpg -i audio0N/final_mix.mp3 \
  -c:v libx264 -pix_fmt yuv420p -color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709 \
  -profile:v high -level 4.2 -crf 18 -preset medium -r 24 \
  -c:a aac -b:a 192k -movflags +faststart 第0N集-标题.mp4
```

> ⚠️ **`-color_range tv` 不能省**（M-84，2026-10-19 首次体检发现）：JPEG 帧是 full-range，不加这行输出会变成 `yuvj420p / pc`，深色渐变底在部分播放器上会发灰。ep01–05 五集全部踩了。
> 编完用 `ffprobe -select_streams v:0 -show_entries stream=pix_fmt,color_range -of csv=p=0 成片.mp4` 确认是 **`yuv420p,tv`**。

> ⚠️ **不要加 `-shortest`**。音频比画面短，加了会截掉尾部静音定格（结尾卡需要停留 1.3–3.8s 让观众读完）。
> 尾部定格靠 `getDuration()` 返回 `total + 1.3~3.8` 实现，画面比音频长是**设计**，不是错误。
> 合片请用每集 `mux_ep{NN}.py`，不要手敲 ffmpeg（ep05 的 mux 脚本已处理帧封面提取、nosub 校验、sha256 输出）。

### 动画引擎契约（`lib/engine.js`）

## 12. 本机踩坑（必看）

1. 渲染必须在 sandbox 外；Chrome 长渲染会随机崩 → 断点续渲
2. 端口残留：每集递增 CDP 9431+2(N-1)，HTTP 8891+(N-1)
3. **删文件不要用 `rm` / `Remove-Item`**（静默失败）→ 用 `python -c "import shutil; shutil.rmtree(...)"` 并回读验证
4. MiniMax 无 SentenceBoundary → 一律 silencedetect 反推句级节拍
5. 大段中文不要直接写进 .py（全角引号会被规范化成 ASCII 引号 → SyntaxError）→ 抽到独立文本/json 读入
6. 程序化生成的图片**必须逐张 Read 确认**再报完成
7. Agnes 图像：比例字段是 `ratio`（不是 size/aspect_ratio）；`size` 静默忽略；`resolution`/`n` 不支持；免费档有队列，重试即成功
8. 判断模型/端点是否存在，**唯一判据是实机调用**，不许凭检索下结论（曾因此误判 `agnes-image-2.5-flash` 不存在）
9. **safe-delete 垫板会拦截批量删帧**（50 个/次触发确认，bash 和 Python 都拦）→ 删整堆帧目录前先 `os.rename` 改名留作备份，渲染器自动建新目录（M-17）
10. **渲染 chrome 会每 2–3 分钟被反复杀**（TargetCloseError）→ 写 resume 循环（`for i in $(seq 1 200)`，每次跳过已存帧）+ 每轮 `taskkill //F //IM chrome-headless-shell.exe` 清 orphan；orphan 堆积会加剧崩溃
11. **独立 dbg 脚本 spawn chrome 会 ENOENT**（沙箱只放行已知脚本路径）→ 调试页面状态往 `render_ep{NN}.js` 里加一个 mode（如 `dbg`），别写独立 spawn 脚本
12. 旧帧备份目录（frames_ep01_v7/v9/v10）会累积占用 ~0.8GB/版，交付定稿后提醒用户清理
