# R5 · 生产流程（15 步）

> 这份文档是**操作手册**：每一步做什么、产出什么文件、过哪道门。
> 读它的时机：开工时、渲染时、不知道下一步干什么时。

---

## 10. 标准流程

| # | 步骤 | 产出 | 门 |
|---|---|---|---|
| 1 | 选题分析（9 问） | 选题结论（做/不做） | QC-0 |
| 2 | 观众 / 平台确认 | 输入契约 1–4 项 | — |
| 3 | 单集目标定义（**先写结尾那句，再写开头**） | 一句话目标 | — |
| 4 | 大纲（七幕 + 变体 + 升维型） | 大纲表 | — |
| 5 | 查重 | 查重记录 | QC-1 |
| 6a | 检索稿 | 资料清单 | — |
| 6b | 事实台账 + 改写稿 | `FACTS.md` + 脚本 | QC-20 → QC-2 |
| 7 | **开场三件套** | 钩子六句 + 赌注句 + 拆好的字幕 | **QC-27 / QC-28** |
| 8 | 分镜设计 → **分镜板 SVG** | 分镜板 | QC-17 |
| 9 | 素材预处理 | 图片/插画（含风格闸） | QC-15 / QC-18 |
| 10 | 音频构建 | `final_mix.mp3` | QC-3 / QC-5 |
| 11 | HTML 动画（句级驱动） | `standalone.html` + `timeline.js` | QC-4 / QC-11 / QC-13 |
| 12 | probe → 全量渲染 → 编码 | `frames/` + `.mp4` | QC-9 |
| 13 | 质检门全跑 | 报告 | QC-0~28 |
| 14 | 逐帧验收 + 通俗化 + 空画面 + 重叠 + **体检** | `epcheck` 报告 | QC-21/22/23/24/26 + **QC-29** |
| 15 | 交付 + 归档 + 复盘回写 | 三件套 + `SERIES.md` 更新 | QC-7/8/16/19 |

### 第 3 步为什么"先写结尾"

结尾那句决定了这一集到底在说什么。**目标定不下来，开头一定散。**
写完结尾句，再回头看开场六句——你会发现很多开场之所以空，是因为根本不知道要走到哪。

### 第 7 步：开场三件套（成本最低的完播率杠杆）

三件事必须在这一步一次做完：

1. **开场钩子**按 R1 §6 六句范式写，前 8 秒零前置知识 → 自查六条硬指标
2. **赌注句**按 R1 §7 写在片头后 3 秒，自带钩子属性 → 对照系列台账的比分
3. **拆字幕**：任何一句 >22 字或预计 >4.5s，**在这一步就拆**成两 cue

→ **QC-27 / QC-28**，**在写 HTML 之前跑**。
此时改字零成本；渲染后发现必然重录重渲。

## 10.1 每集目录的标准文件清单

```
ep0N_<集名>/
├── FACTS.md                 # 事实台账（QC-20）
├── 脚本.md                   # 七幕脚本 + 钩子分布表
├── 分镜板.svg                # 分镜层（QC-17 查时序：必须早于 HTML）
├── timeline.js              # 句级时间轴（SUBS + total + intro）
├── standalone.html          # 动画本体（含 engine.js）
├── render.js                # 渲染驱动（probe / 全量 / resume）
├── build_audio.py           # 三层声轨 + 片头 BGM 合成
├── gen_srt.py               # 字幕生成（跳过 nosub）
├── mux.py                   # 合片（帧 + 音频 → mp4，含 colour range）
├── frames/                  # 渲染帧 frame_%06d.jpg
├── audio/                   # final_mix.mp3 + 分层 stems
├── cover_34.jpg             # 1200×1600 封面
├── 发布文档.md               # 标题/描述/标签/封面说明
├── PROGRESS.json            # 进度（脚本维护）
└── verify/                  # 验算脚本与输出
```

**QC-10 每次从模板复制后必查**：目录里不能有上一集的残留（旧帧、旧脚本、旧集名）。
最常见的事故是"复制了模板但忘了改集名"，于是封面和片头都写着上一集的号。

## 10.2 渲染命令模板

```bash
# probe：先渲少量关键帧，确认构图与元素位置
node render.js probe 0.8 6 20 40 120 200

# 全量（建议写 resume 循环，见 §12）
node render.js

# 编码（定稿参数）
ffmpeg -y -framerate 24 -start_number 0 -i frames/frame_%06d.jpg -i audio/final_mix.mp3 \
  -c:v libx264 -pix_fmt yuv420p -color_range tv -colorspace bt709 \
  -color_primaries bt709 -color_trc bt709 \
  -profile:v high -level 4.2 -crf 18 -preset medium -r 24 \
  -c:a aac -b:a 192k -movflags +faststart <集名>.mp4
```

> ⚠️ **`-color_range tv` 不能省**：JPEG 帧是 full-range，不加这行输出会变成
> `yuvj420p / pc`，深色渐变底在部分播放器上会发灰。
> 编完用
> `ffprobe -select_streams v:0 -show_entries stream=pix_fmt,color_range -of csv=p=0 成片.mp4`
> 确认是 **`yuv420p,tv`**。

> ⚠️ **不要加 `-shortest`**。音频比画面短，加了会截掉尾部静音定格
> （结尾卡需要停留 1.3–3.8s 让观众读完）。
> 尾部定格靠 `getDuration()` 返回 `total + 1.3~3.8` 实现，**画面比音频长是设计，不是错误**。

> **合片不要手敲 ffmpeg**：写一个 `mux.py`，把「帧目录 → 封面提取 → nosub 校验 →
> sha256 输出」固定下来。手敲参数每次都会漏一项。

## 10.3 动画引擎契约

`standalone.html` 必须实现三个入口：

| 入口 | 契约 |
|---|---|
| `window.videoTimeline.seek(t)` | **纯函数式**：任意 t 都得到相同画面（渲染器逐帧调用，可能乱序） |
| `window.getDuration()` | 返回 `total + 1.3`（尾部定格） |
| `mk(scene, idx)` | 返回该句起始绝对秒；索引 = 该句在场景内 0 基序号 |

**三条硬约束**：

1. `seek(t)` 不能有累积状态。动画必须由 t 直接算出，不能靠"每帧 +1"。
2. `mk()` 的节拍来自 `SUBS[scene][idx].start`，不是自己累加。
3. `nosub` 的 cue 仍在 SUBS 里（`mk()` 要用），只是不上屏。

## 10.4 音频构建

```
build_audio.py
  ├── 读 timeline.js（取得每句起止）
  ├── 调 TTS 合成每句 → 按 start 摆放
  ├── 加音效层（whoosh / 落位 / 矛盾音）
  ├── 加垫乐层（分幕性格不同）
  ├── 加片头 BGM（第四层，0–1s 全开，3.5s 淡完）
  └── 母带归一化 -3dBFS → final_mix.mp3
```

**两个常见错误**：

- **先合音频再改脚本**：字数一变，节拍全错。**脚本定稿后才建音频。**
- **人声电平跟着垫乐走**：应该反过来——垫乐给人声让路。

## 11. 交付

**三件套**（命名建议固定，便于归档脚本识别）：

```
<系列名>-第0N集-<集名>.mp4
<系列名>-第0N集-<集名>-封面.jpg
<系列名>-第0N集-<集名>-发布文档.md
```

**归档**：

```bash
MEV_DST=/your/archive python scripts/archive_flat.py      # 全部
python scripts/archive_flat.py ep01                        # 只归档某一集
```

脚本会：平铺复制 → 清理非白名单残留（保留 MANIFEST）→ sha256 回读比对 → 写 `MANIFEST_flat.md`。
**归档后必须回读验证**（列目录、比字节数），不许以"命令没报错"当成功。

### 发布文档必含四节

| 节 | 内容 | 要求 |
|---|---|---|
| 一、标题 | 主标题 + 2 个备选 | ≤20 字；含数字或反常识断言；**不与近 3 集重样** |
| 二、视频描述 | 100–200 字 | 首句 = 钩子；中段 = 本集核心结构一句话；尾句 = 留白问题；**不含"点赞关注"套话** |
| 三、标签 | 8–12 个 | 大类 + 中类 + 具体 + 长尾；**不堆无关热词** |
| 四、封面 | 用哪张 + 裁切说明 | 说明主体位置与平台裁切风险 |

**复盘回写**：更新 `SERIES.md`（交付台账 / 比分 / 钩子台账 / 变体与升维型记录），
并把这一集踩到的坑追加到项目自己的 `LESSONS.md`（下次开新集先读）。

## 12. 常见坑（跨平台通用）

1. **长渲染会崩**：Chrome 连续渲几百帧后随机崩。→ 写 resume 循环：
   `for i in $(seq 1 200); do node render.js; done`，每轮跳过已存帧，
   并在每轮开始前清理 orphan 进程。
2. **端口残留**：每集用完的调试端口不释放。→ 每集递增端口（CDP 9431+2N / HTTP 8891+N），
   或每轮开始前显式 kill。
3. **删文件静默失败**：某些环境的 `rm` / `Remove-Item` 会走回收站垫片，
   失败也不报错。→ 用 Python `shutil.rmtree` 并**回读验证目录确实不存在**。
4. **TTS 不给句级时间戳**：多数服务只返回整段音频。
   → 用 `silencedetect` 反推句级节拍，或用固定速率 + 人工校准。
5. **大段中文写进 .py 会炸**：全角引号被编辑器规范化成 ASCII 引号 → SyntaxError。
   → 文案抽到独立 `.md` / `.json` / `.txt`，代码只读文件。
6. **程序生成的图片必须逐张打开看**再报完成。生成"成功"不等于"正确"。
7. **图生图 API 的参数名各家不同**（`ratio` / `size` / `aspect_ratio`），
   传错会**静默忽略**而不是报错。→ 第一次调用就验证输出尺寸。
8. **判断某个模型/端点是否存在，唯一判据是实机调用**，不许凭检索下结论。
9. **批量删帧会被安全垫片拦截**（触发确认）。→ 删整堆帧前先 `os.rename` 改名留作备份，
   渲染器会自动建新目录。
10. **调试脚本 spawn 浏览器可能 ENOENT**（沙箱只放行已知脚本路径）。
    → 不要写独立的 spawn 脚本，在现有 `render.js` 里加一个 mode。
11. **旧帧备份目录会累积**（每版可能几百 MB 到 1GB）。
    → 定稿交付后清理，只留最终版。
12. **编码色域**：见 §10.2 的 `-color_range tv`。这是跨项目最常复发的一个坑。
