# R7 · 小红书图文笔记（9 图 + 文案）

> 视频定稿后同步产出图文版。也可以单独做——九图本身就是一篇完整的图文笔记。
> 读它的时机：视频定稿后，或用户说"做成小红书贴图"时。

---

## 13.1 硬约束

| 项 | 规则 | 为什么 |
|---|---|---|
| 张数 | **9 张** | 平台上限 18；9 是"讲得完又划得动"的黄金数 |
| 尺寸 | **1080×1440（3:4）** | 小红书首图主流比例 |
| 视觉一致性 | **九张必须是同一种图**——同一模板程序化渲染 | **严禁 AI 插画与信息图混排**，混排会显得像拼凑 |
| 顺序 | 严格 = 内容顺序 | 划一遍读完一集 |
| 生成方式 | HTML/CSS/SVG + headless Chrome，零成本 | 不用图像生成模型，保证九张完全对齐 |

### 九张固定叙事位

| 序 | 角色 | 图形语言 |
|---|---|---|
| 01 | **封面** | 本集核心悖论/公式的大字排版 + 署名 |
| 02 | **困局** | 左右双卡对照（旧认知 vs 新认知） |
| 03 | **动手** | 三卡递进（同一动作做三遍，看变化） |
| 04 | **造物** | 公式 + 参数注解，或 A→B 双面板 |
| 05 | **穿透** | 中心大结论 + 两侧出处卡 |
| 06 | **概念** | ①②③ 三条规矩横条 |
| 07 | **金句** | 两行大字 + 副注 + 手绘星星点缀 |
| 08 | **赌注** | 二分徽章 + `+1` 爆炸框（做系列时放比分） |
| 09 | **预告** | 本集核心图形复用 + 下集署名 |

**图形语言白名单**：只用上表九种。
新集**只换内容不换语言**——读者才会形成"这是同一本书的九页"的认知，
这是复访率的结构性来源。

> **08 与 09 别搞混**：08 是"赌注/母题"（给谁记分），09 是"预告"（下一集）。
> 命名时按这个顺序，归档脚本和上传顺序都依赖它。

## 13.2 版式骨架（九张严格共用，一分不动）

```
品牌区   logo 68px + 系列名 47px（衬线 700 / 字距 .24em）+ 口号 12.5px
        右上：EP.0N · 集名 ｜ 0N / 09
细线（主色渐变）
标题区   固定 height: 300px，60px 衬线，行高 1.52
图形区   viewBox 一律 0 0 880 560
一句解说 ≤23 字，26px，不折行
页脚     口号 + 小品牌标识（19px logo + 14.5px 字）
```

**四条必须遵守的版式纪律**：

1. 标题区**必须固定高度**，否则内容长度不同的九张，图形区会高低参差。
2. 图形区 viewBox **必须同一尺寸**，缩放后九张才对得齐。
3. 品牌区**九张分毫不动**——"系列感"只来自这里。
4. **图形区内容必须收在 y ≤ 545**：viewBox 高 560，超出即被静默裁切（F1），
   贴底线以下观感压脚（F2）。
   封面三行底部结构的标准坐标：**金句 y=500 / 分隔线 y=522 / 底句 y=545**。

> **顶部说明文字（23px + letter-spacing 2）单行最多约 33 个汉字当量**，超出会右侧出界（F1）。
> 宁可删字，不要缩小字号——字号一缩，九张的视觉重量就不齐了。

## 13.3 视觉基底

- **底色**：深色渐变 + 中部聚光 + 顶部暖光 + 暗角（配色由 `brand.json` 的 accent 派生）
- **纸感颗粒**：`feTurbulence` data-URI / opacity .075 / `mix-blend-mode: overlay`
- **画框**：主色双细线 + 四角规矩线
- **字体**：标题/品牌用衬线（Noto Serif SC / 思源宋体），解说/标签用无衬线（Noto Sans SC / 苹方）
- **禁**：72px 网格、近黑纯色底、仪表盘式角标

### 配色引擎

把颜色抽成一张表，整页色彩靠 `recolor()` 做字符串置换：

```js
// 键：原色值 → 值：目标色值
const PALETTES = {
  teal:    { accent: '#F0B44A', bg: ['#032322', '#075049', '#0B6E62', '#032322'], grayMap: {...} },
  terra:   { accent: '#E8A33D', bg: ['#2A1208', '#5C2A14', '#7A3A1C', '#2A1208'], grayMap: {...} },
  // 每套配色必须自带 grayMap（见 §13.7 第 4 条）
};
```

**换整套配色不需要改一行 SVG 代码**——只要 `PAL=teal node render_xhs.js`。

**新集不是"只改 slides 数据"**：九张的**图形语言同族、具体图形必须按本集数据重画**。

正确做法：

1. 复制上一集的 renderer
2. 只改三个常量：`EP_NAME` / `EP_NUM` / `slides`
3. `art` 里按本集内容重写
4. **骨架（CSS / logoMark / GRAIN / recolor / pageHTML / 渲染主循环 / MEASURE）一行都不要改**

> ⚠️ **复制后必须逐张确认 02–09 真的换了内容**。
> 曾出现过"只有封面换了，后面八张全是上一集"的情况，差点带病交付。

## 13.4 文案（`发布文案.md`）

**正文硬上限 1000 字符**（含标点、空格、换行、话题标签）。
**必须用脚本实测两种口径**（含空白 = 最保守 / 不含空白），**禁止凭感觉估字数**。
（曾出现第一版 1023 字符已超限而不自知。）

超限时删减优先级：

1. 删"复述图里已经画出来内容"的句子
2. 压缩长句
3. 合并分隔段空行

**不动叙事结构。**

### 文档固定六节

| 节 | 内容 | 硬要求 |
|---|---|---|
| 一、标题 | 5 条备选 + 类型 + **字数列** | ≤20 字（平台上限） |
| 二、正文 | 可直接复制整段 | ≤1000 字符；`—` 分隔段与九图节奏一一对应 |
| 三、图片对应 | 9 行表 | 图号 / 文件名 / 讲什么 |
| 四、发布建议 | 首图·话题·时间·置顶·合规 | 话题 7 个，前 3 必带 |
| 五、字数说明 | 两种口径实测值 + 删减明细 | **先量后写**，不许先写数字再凑内容 |
| 六、事实核对 | 与成片脚本一致 | 争议事实必须留白 |

小红书**合集简介 ≤50 字符**，前 15 字必须完成钩子（超出部分会被折叠）。

### 精简版格式（推荐，字数压力小一半）

```markdown
# <系列名> · 第NN集《集名》

副标题：一句话钩子

01 封面：…
02 困局：…
03 动手：…
04 造物：…
05 穿透：…
06 概念：…
07 金句：…
08 赌注：第 NN 集 · 记分 A : B，后续集数揭晓。…
09 预告：下集：…

本集金句：…
```

- 九段**必须与九张图一一对应**，编号顺序不可调
- 每段写"图里画了什么 + 一句它意味着什么"，**不重复图上已有的数字**（那是图的活）

## 13.6 验收

### 机器门 A · 版式缺陷（`assets/qc_xhs.js`，FAIL = 0 才交付）

渲染器里挂：

```js
const { qcPage } = require('./assets/qc_xhs.js');
if (process.env.QC) { const r = await qcPage(page); console.log(JSON.stringify(r)); }
```

命令加 `QC=1` 即输出逐张报告。六条判据全部基于 **DOM 实测包围盒**：

| 码 | 判据 | 阈值 | 抓什么 |
|---|---|---|---|
| F1 | 元素 bbox 越出 viewBox | 容差 1px | 文字被静默裁切 |
| F2 | 文字底边低于 520 | 520，超 560 升级 FAIL | 图形太靠底部 |
| F3 | 两个 text 包围盒相交 | > 较小框 20% | 文字压文字 |
| F4 | 文字被非卡片图形压住 | > 文字框 50% | 文字压图形 |
| F5 | 图形区与解说/页脚相交 | — | 图形压版式 |
| F6 | 输出 PNG 必须 1080×1440 | 精确 | 尺寸错 |

**F4 豁免**：① 文字被图形完整包含（圆形徽章 + `+1` 爆炸框）；
② 图形面积 < 文字 30%（侧旁小装饰）。

> ⚠️ **量包围盒只能用 `getBoundingClientRect()`，不能用 `getBBox()`**——
> 后者返回元素自身坐标系，不含 `<g transform="translate(...)">`，
> 会把所有 translate 过的元素误判成越界（曾一次误报 11 处）。

> ⚠️ `page.evaluate` 里的函数**取不到 Node 侧常量**，
> `CARD_MIN_AREA` 这类必须当参数传进去，否则 `xxx is not defined`。

### 机器门 B · 几何居中（`assets/xhs_center.py`）

对已渲染 PNG 在 **art 区**逐行做墨迹投影，算内容块的
`first / last / 上留白 / 下留白`：

| 码 | 判据 | 阈值 |
|---|---|---|
| G1 | **几何居中**：\|上留白 − 下留白\| ÷ art 高 | ≤5% |
| G2 | 内容占 art 高（填充度） | ≥55%，防大片空 |
| G3 | 最大连续空白断层 | ≤30% art 高 |

```bash
python assets/xhs_center.py --dir <输出目录>     # 批量测 G1/G2/G3
python assets/xhs_center.py <png> [<png> ...]    # 单张
```

> ⚠️ **目标必须是「内容块几何中心」对齐 art 中线，不是「墨迹加权重心」**——
> 加权重心会被底部大字/粗线拉偏，对齐后内容整块跑到偏上，下方留一大片空，比原状更难看。

**自动居中的落地方式**（不要手调 y 坐标）：

```css
.art svg { transform: translateY(var(--dy, 0%)); }
```
```html
<div class="art" style="--dy: ${(CENTER_DY[s.idx] || 0).toFixed(2)}%">
```
```js
const CENTER_DY = { 1: 0, 2: -1.6, /* … 值 = 实测平移量 vb ÷ 5.6，负 = 向上 */ };
```

流程：渲一遍 → 测 G1/G2/G3 → 把平移量写进 `CENTER_DY` → 再渲 → 复测。

> ⚠️ 墨迹判定**不能用固定背景色比对**——背景有渐变，会把整行误判成有内容，
> 得出"下留白恒为 1px"的假数据。
> 改用双路：`暖色像素（r>140 且 r−b>40 且 r−g>15）` **或** `亮度 > 165`。

> ⚠️ art 区中线写成 `(ART_TOP+ART_BOT)/2`，写成 `ART_TOP+ART_BOT/2` 会让偏心值整整差一半。

### 人工门

1. **九张逐张打开看**——配色气质、图形是否切题、信息层次是否合理
2. `MEASURE=1` 让浏览器输出 `getBoundingClientRect`，
   实测品牌区 / 标题区 / 图形区 / 解说 / 页脚的真实像素位置
3. 像素采样确认九张色相一致
4. 淡色元素**必须实测对比度**（峰值差 ≥50），不许凭"我调亮了一点"交付

> ⚠️ **目视的已知局限**：目视会漏"比例类"缺陷。
> 曾出现过封面图形整体偏下，逐张目视没发现——因为绝对位置正常、
> 只是**相对 art 区的重心失衡**，缩略图上不刺眼。
> **结论：目视只用来抓"切题/气质/明显错"，比例与位置一律交给机器门量。**

### 文案门

用脚本实测两种口径字符数（含空白 / 不含空白），**≤1000 才算过**。

## 13.7 踩坑（全部实际踩过）

1. **SVG `linearGradient` 默认 `objectBoundingBox`** → 用在纯竖线上 bbox 宽度 = 0、
   用在纯横线上 bbox 高度 = 0 → 渐变失效 → **整个元素不渲染**。
   两次踩同一坑：logo 的竖线整根消失、时间轴主干整条消失，页面看起来像"少画了一根轴"。
   **修法只有一条：`gradientUnits="userSpaceOnUse"` + 绝对坐标。凡给 line 上渐变，必须写 userSpaceOnUse。**

2. **预览图被缩放**（1080 → 810）→ 目测"偏下/被裁"全是误判。
   用 `MEASURE=1` 实测，不要用眼睛猜像素。

3. **viewBox 坐标越界会静默裁切**，不报错不警告。所有图形必须收在 viewBox 内。

4. **硬编码灰不随配色走** → 换底后这些元素直接"消失"：
   深青底上 `#5C6675` 标签不可见、`#8E5A2A` 幽灵数字与底同色。
   **每套配色必须配 `grayMap`**，把冷灰映射成同色系可见色。

5. **深色底上的幽灵水印要用比底"亮"的颜色**，不是同色系更深色。

6. `recolor()` 里部分色值在 `grayMap` 循环**之前**就被替换，
   grayMap 里再写这些键是**死代码**，永远命中不到。

7. **baseline 上移不等比**：`y` 每减 10 viewBox 单位 ≈ 实际 13px（SVG 被缩放到 752px 高）。
   用户说"往上移一点"时给约 30–40 单位。

8. **九张里只要有一张尺寸/比例不同，整组就散了**。
   用同一份 CSS、同一套渲染函数、同一轮截图，不要手工补一张。
