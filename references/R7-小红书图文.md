### 13.2 版式骨架（九张严格共用，一分不动）

```
品牌区   logo 68px + 万物有数 47px（Noto Serif SC 700 / 字距 .24em）+ 口号 12.5px
        右上：EP.0N · 集名 ｜ 0N / 09
金色渐变细线
标题区   固定 height:300px，60px 思源宋体，行高 1.52
图形区   viewBox 一律 0 0 880 560
一句解说 ≤23 字，26px，不折行
页脚     口号 + 小品牌标识（19px logo + 14.5px 字）
```

- 标题区**必须固定高度**，否则内容长度不同的九张图形区会高低参差。
- 图形区 viewBox **必须同一尺寸**，缩放后九张才对得齐。
- 品牌区九张分毫不动——"系列感"只来自这里。
- **图形区内容必须收在 y ≤ 545**：viewBox 高 560，超出即被静默裁切（F1），贴底线以下观感压脚（F2）。
  封面三行底部结构的标准坐标：**金句 y=500 / 分隔线 y=522 / 底句 y=545**。
- **顶部说明文字（23px + letter-spacing 2）单行最多约 33 个汉字当量**，超出会右侧出界（F1）。
  宁可删字，不要缩小字号——字号一缩，九张的视觉重量就不齐了。

### 13.6 验收（缺一不可）

**机器门（QC-1 自动缺陷检查，2026-10-19 起强制，FAIL=0 才算交付）**

渲染器里挂 `const { qcPage } = require('../_qc/qc_xhs.js');`，截图前跑 `if (process.env.QC) {...}`，
命令加 `QC=1` 即输出逐张报告（母版在 `assets/qc_xhs.js`）。六条判据全部基于 **DOM 实测包围盒**：

| 码 | 判据 | 阈值 | 实测踩过的坑 |
|---|---|---|---|
| F1 | 元素 bbox 越出 viewBox（文字被静默裁切） | 容差 1px | **ep21–25 五集封面底部各越界 5–47px**（沿用 ep20 的 y=565/600，viewBox 只有 560）；ep22–25 说明文字右侧溢出 40–143px |
| F2 | 文字底边低于 520（图形太靠底部） | 520，超 560 升级 FAIL | 只对 `text` 判定；分隔线/卡片底板不判（viewBox 内都合法） |
| F3 | 两个 text 包围盒相交 | > 较小框 20% | ep25 封面公式与副标行盒重叠 76% |
| F4 | 文字被非卡片图形压住 | > 文字框 50% | 豁免：① 文字被图形完整包含（圆形比分章/爆炸框 +1）② 图形面积 < 文字 30%（侧旁小装饰） |
| F5 | 图形区与 cap 解说 / bot 页脚相交 | — | 版式骨架固定，一般不触发 |
| F6 | 输出 PNG 必须 1080×1440 | 精确 | — |

⚠️ **量包围盒只能用 `getBoundingClientRect()`，不能用 `getBBox()`**——后者返回元素自身坐标系，
不含 `<g transform="translate(...)>`，会把所有 translate 过的元素误判成越界（ep21 一次误报 11 处）。
⚠️ `page.evaluate` 里的函数**取不到 Node 侧常量**，`CARD_MIN_AREA` 这类必须当参数传进去，否则 `xxx is not defined`。

**构图门（QC-2 几何居中，2026-10-19 用户指正后补建，FAIL=0 才算交付）**

母版 `assets/xhs_center.py` + `assets/center_pass.py`（Python，系统 Python 跑）。
对已渲染 PNG 在 **art 区（页面 y 591–1179，MEASURE=1 实测）** 逐行做墨迹投影，算内容块的
`first / last / 上留白 / 下留白`：

| 码 | 判据 | 阈值 |
|---|---|---|
| G1 | **几何居中**：\|上留白 − 下留白\| ÷ art 高 | ≤5% |
| G2 | 内容占 art 高（填充度） | ≥55%，防大片空 |
| G3 | 最大连续空白断层 | ≤30% art 高 |

⚠️ **目标必须是「内容块几何中心」对齐 art 中线 280，不是「墨迹加权重心」**——
加权重心会被底部大字/粗线拉偏：ep25 封面按加权重心对齐后，块整体跑到偏上 85px、下方空 181px，比原状更难看。
**实测 45 张里 32 张偏心 >8%**（封面全偏下 8~22%、07/08 全偏上 13~15%），是系统性问题不是孤例。

**自动居中三步**（新集必做，不要手调 y 坐标）：

```bash
python assets/center_pass.py reset      # CENTER_DY 归零并渲染出原始状态
python assets/center_pass.py apply      # 实测重心 → 写回渲染器的 CENTER_DY 表（再渲一遍）
python assets/xhs_center.py --dir <输出目录>   # 复测 G1/G2/G3
```

渲染器侧三处配套：
CSS `.art svg { transform: translateY(var(--dy,0%)); }` ＋
HTML `<div class="art" style="--dy:${(CENTER_DY[s.idx]||0).toFixed(2)}%">` ＋
`const CENTER_DY = {...}`（值 = 实测平移量 vb ÷ 5.6，换算成 viewBox 高的百分比，负 = 向上）。
`center_pass.py apply` 会自动改这三处。

⚠️ 墨迹判定**不能用固定背景色比对**——背景有 radial/linear 渐变，会把整行误判成有内容，
实测得出"下留白恒为 1px"的假数据。改用双路：`暖金色(r>140 且 r−b>40 且 r−g>15)` **或** `亮度>165`。
⚠️ 脚本里 art 区中线写的是 `(ART_TOP+ART_BOT)/2`，写成 `ART_TOP+ART_BOT/2` 会让偏心值整整差一半。

**人工门（机器查不出的仍要看）**

1. **九张逐张 Read 目视**——配色气质、图形是否切题、信息层次是否合理

### 13.7 小红书踩坑（全部实际踩过）

1. **SVG `linearGradient` 默认 `objectBoundingBox`** → 用在纯竖线上 bbox 宽度 = 0、用在纯横线上 bbox 高度 = 0 → 渐变失效 → **整个元素不渲染**。两次踩同一坑：ep01 logo 三根刻痕柱（竖线）整根消失；ep02 时间轴主干（横线）整条消失，只留下端点圆点和年份，页面看起来像"少画了一根轴"。修法只有一条：`gradientUnits="userSpaceOnUse"` + 绝对坐标。**凡给 line 上渐变，必须写 userSpaceOnUse**。
2. **预览图被缩放 0.75**（1080→810）→ 目测"偏下/被裁"全是误判。用 `MEASURE=1` 实测，不要用眼睛猜像素。
3. **viewBox 坐标越界会静默裁切**，不报错不警告。所有图形必须收在 viewBox 内。
4. **硬编码灰不随配色走** → 换底后这些元素直接"消失"：青底上 `#5C6675` 标签不可见、`#8E5A2A` 幽灵数字与底同色。**每套配色必须配 `grayMap`**，把冷灰映射成同色系可见色。
5. **深色底上的幽灵水印要用比底"亮"的颜色**，不是同色系更深色（ep01 幽灵「3」连改三次才对）。
6. `recolor()` 里部分色值在 `grayMap` 循环**之前**就被替换（如 `#7D8797 → P.dim`），grayMap 里再写这些键是**死代码**，永远命中不到。
7. baseline 上移不等比：`y` 每减 10 viewBox 单位 ≈ 实际 13px（SVG 被缩放到 752px 高）。用户说"往上移一点"时给约 30–40 单位。
