# R1 · 叙事结构：七幕升维

> 这份文档解决一个问题：**同一个知识点，怎么讲才有人看完。**
> 读它的时机：选题、写脚本之前。写代码阶段不用回头看。

---

## 1. 底层逻辑：观众为什么留下来

不是为知识，是为**悬念**。所以每一集不是"介绍一个概念"，而是：

> **一个人被什么麻烦逼到墙角，然后造出了一个原本不存在的东西。**

这句话拆开是三个零件，缺一个就塌：

| 零件 | 作用 | 缺了会怎样 |
|---|---|---|
| **麻烦** | 制造缺口（观众想知道"那怎么办"） | 变成知识罗列，第一分钟就掉人 |
| **造物** | 兑现缺口（"原来是这样"） | 悬念悬空，观众觉得被骗 |
| **升维** | 把具体案例变成可迁移的思维工具 | 看完就忘，不收藏不转发 |

**判断一个选题能不能做，就看这三个零件是否能同时成立。**

## 2. 选题体检 9 问（QC-0）

逐条回答，**不要凭感觉打勾，要写出具体内容**。

| # | 问题 | 必须 | 不合格的信号 |
|---|---|---|---|
| 1 | 用一句话说出"他遇到的麻烦"是什么？ | ✅ **必过** | 说不出麻烦，只能说"他想研究 X" |
| 2 | 这个麻烦有没有一个**具体、可看见、可触摸**的物？ | ✅ **必过** | 全是抽象概念，没有一个能画出来的东西 |
| 3 | 造出来的那个东西，能不能在 **10 秒**内让人看懂它在干什么？ |  | 需要三分钟铺垫才明白 |
| 4 | 有没有一个**反常识**的结论？（"他居然……"） | ✅ **必过** | 结论是"所以他很伟大"这种正确但无信息量的话 |
| 5 | 能不能升维成一个**可迁移的思维动作**？ | ✅ **必过** | 只能说"这个故事告诉我们" |
| 6 | 关键事实有没有 **≥2 个独立来源**？ |  | 只有百科一个来源 |
| 7 | 有没有**人**？（有名有姓、有处境、有代价） |  | 只有概念演变，没有人的选择 |
| 8 | 与同系列已有集是否**重复**？（角度 / 钩子 / 演示） |  | 和上一集讲的是同一件事的两种说法 |
| 9 | 目标观众能不能在**头 8 秒**听懂第一句？ |  | 第一句就要前置知识 |

**判停：第 1、2、4、5 条任一不过 → 换题，不要硬做。**
硬做的结果是：结构完整、画面精致、完播率很低。

> **第 8 条说明**：单条视频跳过即可；做系列必须查（见 §8 查重）。

## 3. 七幕表（结构的骨架）

| 幕 | 名称 | 时长 | 硬要求 |
|---|---|---|---|
| 0 | 片头 | **≤1.0s** | 品牌元素一个不少（logo + 系列名 + 口号 + 集数主题 + 右上角集标）；**同起片头 BGM**；0.12s「唰」飞入 |
| 1 | **奇景** | 12–20s | **片头结束后前 3 秒抛赌注**（§7）；一个可看见的具体物**并带数量**；一句断言不给结论；**开场按 §6 六句范式写** |
| 2 | **困局** | 30–45s | **4–8 个镜头**，含 1 个道具锚；★ 必须出分镜板 |
| 3 | **动手** | 22–32s | "跟着我算 / 跟着我做"，**10 秒内能完成一步** |
| 4 | **造物** | 45–70s | ★ 全集最重要的动画段；≥1 个"画面自解释"演示（不看旁白也懂） |
| 5 | **穿透** | 35–50s | 领域跨越链条，举例具体到人物与年份，**≥1 个非西方例子**（选题允许时） |
| 6 | **升维** | 25–40s | 收束为单一意象 + 锚点大字；**末尾留白 1.5s 全静音** |
| 7 | **追问** | 12–18s | 下集预告 + 赌注对账 + 关键词铭牌；预告帧 = 下集奇景首帧 |

**合计 182–276s（3–4.5 分钟）。**

### 3.1 每幕的一句话职责

写脚本时逐幕自问：**这一幕结束时，观众脑子里多了一个什么问题？**

| 幕 | 观众此刻的问题 | 如果这一幕删掉 |
|---|---|---|
| 奇景 | "这有什么稀奇？" | 没有悬念，后面全是灌输 |
| 困局 | "那怎么办？" | 造物没有价值（不痛就不需要解药） |
| 动手 | "我好像也能做" | 观众从旁观者变不进来 |
| 造物 | "原来是这样！" | 全片没有兑现时刻 |
| 穿透 | "影响这么大？" | 观众觉得"跟我没关系" |
| 升维 | "我可以这样看世界" | 不收藏、不转发 |
| 追问 | "下一集呢？" | 单条完播可以，系列追更起不来 |

### 3.2 时长纪律

- **幕 4（造物）必须是全片最长的一幕**。它短了，说明你把钱花在了包装上而不是兑现上。
- **幕 1（奇景）不要超过 20s**。前 20 秒还没进入"麻烦"，人就走了。
- **幕 6（升维）宁可短，不要注水**。一句话能说完的，不要写三句。

## 4. 四种变体（防套路化）

| 变体 | 骨架 | 适合的题材 |
|---|---|---|
| **W · 七幕升维**（主） | 一个人 → 一个麻烦 → 一件造物 | 默认，80% 的选题 |
| **A · 双线对撞** | 两条线并行推进，在中段撞上 | 有竞争、有路线之争、有"同时发现" |
| **B · 思想实验** | 先给一个假设情境，让观众跟着推理 | 抽象概念（无穷、概率、因果、时间） |
| **C · 物的传记** | 以一件物为主角，跟着它穿越时代 | 器物、符号、工具、制度 |

**轮换纪律**：同一变体连续使用 **≤3 集**。第 4 集必须换。
做单条视频时，按题材选最合适的；做系列时，变体本身要排班。

## 5. 升维 7 型（第 6 幕的落点）

| 型 | 做什么 | 例子（抽象示意） |
|---|---|---|
| ① 尺度 | 从局部拉到极大/极小 | 从一滴水拉到整个水循环 |
| ② 视角 | 换一个观察者的位置 | 从"人看地图"换成"地图看人" |
| ③ 时间 | 拉到百年/千年尺度 | 一个今天习以为常的设计，在两百年后变成什么 |
| ④ 概念 | 把这个具体问题抽象成一类问题 | 从"这次分不均"到"所有分配问题" |
| ⑤ 身份 | 换一个主体（不是人） | 从"人怎么适应环境"到"环境怎么筛选人" |
| ⑥ 反身 | 把方法用回它自己 | 用这套推理去检验这套推理 |
| ⑦ 文明 | 落到文明尺度 | 一个技术如何改变了一个文明的走向 |

**纪律**：

- 每集**试 ≥3 型**，选**最不像"总结"**的那个。
- **同型连续两集不重复。**
- **⑦ 文明型每季 ≤1 次**（用多了像宏大叙事，观众免疫）。

**QC-16 判据**：把升维句单独拎出来读。**若只是本集内容总结 → 不合格。**
好例子："这不是他聪明，是他把'不知道'当成了一个可以计算的东西。"
坏例子："所以，这个故事告诉我们，坚持就会成功。"

## 6. 开场钩子：六句范式

**前 8 秒决定 80% 的完播率。** 这一段是全片最贵的 8 秒，必须按结构写，不能凭语感。

### 6.1 六句结构

| 序 | 承担的功能 | 字数上限 |
|---|---|---|
| 1 | **具体可数的物 + 数量**（或一个可看见的动作） | ≤15 字 |
| 2 | 主体入场，动作开始 | — |
| 3 | **建立"不可能"**（没人教 / 从来没有 / 按当时规矩算不下去） | — |
| 4 | 动作 + 悬念拉满 | — |
| 5 | **短句反转，一句一锤** | ≤12 字 |
| 6 | **反问**（观众真的会想脱口回答的那种） | — |

### 6.2 一个中性示范（讲"地图投影"）

| 序 | 台词 | 功能 |
|---|---|---|
| 1 | 一张世界地图，格陵兰岛和非洲差不多大。 | 具体物 + 数量 |
| 2 | 但真实的格陵兰，只有非洲的十四分之一。 | 建立"不可能" |
| 3 | 不是画错了，是**必须**画错。 | 反常识断言 |
| 4 | 你想把一个球，完整地摊平在一张纸上。 | 把观众拉进动作 |
| 5 | 摊不平的。 | 短句一锤 |
| 6 | 那地图为什么要骗你？ | 反问 |

> 这个例子只是**结构示范**，不是选题建议。你可以把同样的六句骨架套在任何题材上。

### 6.3 六条硬指标（写完逐条自查）

1. **第一句 ≤15 字**，含具体可数的物 + 数量，或一个可看见的动作。不写抽象概念、不写年份、不写人名。
2. **前 8 秒零前置知识**——没看过任何一集的人也能听懂。
3. **第 3–4 句建立"不可能"**（没有人教 / 从来没有 / 按当时规矩算不下去）。
4. **第 5 句用短句给反常识结果**，≤12 字，一句一锤。**不要在这一句解释。**
5. **第 6–7 句出反问**，必须是观众真的会想脱口回答的那种。
6. **前 30 秒内至少 1 次提问**（承接 QC-27 钩子密度门）。

### 6.4 禁止的四种开场

| 禁止 | 为什么 |
|---|---|
| ① 承接上一集（"上一集我们说到……"） | 新观众第一句就被劝退 |
| ② 品牌口号开场 | 观众不关心你是谁 |
| ③ 年份 / 人名开场（"一六八七年，牛顿……"） | 没有人，没有画面，没有悬念 |
| ④ "今天我们来聊聊……" | 宣告式开场 = 告诉观众"接下来是上课" |

## 7. 赌注机制（把最强的悬念提前）

> **为什么**：系列最值钱的东西不是任何一个知识点，而是**贯穿全系列的那个悬念**。
> 但如果它只在片尾结算，观众看完全片才知道有赌局——等于把悬念放在了观众已经离开之后。

### 7.1 两种赌注

| 类型 | 适用于 | 形式 |
|---|---|---|
| **系列核心诘问** | 做系列（≥10 集） | 一个二分问题，每集给某一方记一分，终章揭晓总分 |
| **单集赌注** | 做单条 | 一条本集将要验证或推翻的断言（"你会以为 X，其实……"） |

**核心诘问的写法要求**：

1. 必须是**二分**的（A 还是 B），不能是开放式问题。
2. 两边都**有人真心相信**（否则没有对抗）。
3. **每集都能给出一个具体的记分理由**，不能靠立场硬记。

### 7.2 三条位置

| 位置 | 动作 | 时长 |
|---|---|---|
| 片头结束（1.0s）后 | **1.0–4.0s 亮出本集赌注** | ≤3s |
| 全片中段 | 至少 **1 次回扣**（"这一分还没记完"） | 4–6 字插句 |
| 结尾（幕 7） | **对账**：给出答案 + 当前比分 | 结尾卡 |

### 7.3 三条写法纪律

1. **赌注句必须自带钩子属性**，不许写成干巴巴的宣告。
   - ❌ 差：「这一集，我给"A"记一分。」（纯宣告，无信息压力）
   - ✅ 好：「这一集我给"A"记一分。你要是不同意，看完再说。」（有对抗）
   - ✅ 更好：「这一集，我要给"A"加一分。但你先别信我——」（把裁决权交给观众）
2. **赌注句照常上字幕**，行宽受 R2 §4.5 约束（≤22 字）。
3. **赌注方向必须与系列台账一致**。改分前先查台账——分数是跨集的连续账，不能每集随手取。

**画面实现**：赌注句对应的拍，在角标下方（y ≥ 300）出一条**单行赌注带**
（无卡片底板，只有一条 2px 主色细线 + 文字），或复用比分牌组件的静态版。
**不要**做成整屏大字卡（会与幕 1 奇景撞车）。

## 8. 查重（QC-1）

做系列时，写新集前必须查五+二项：

| 项 | 查什么 | 重复了会怎样 |
|---|---|---|
| 角度 | 是否和已有集讲同一件事 | 观众觉得你在灌水 |
| 钩子 | 开场六句的结构是否雷同 | 连着看两集会有"又是这套"的感觉 |
| 变体 | 是否连续 ≥4 集同一变体 | 节奏单调 |
| 升维型 | 是否和上一集同型 | 结尾都一个味 |
| 核心演示 | 是否有同一套动画 | 素材复用痕迹明显 |
| 赌注 | 是否连续给同一方记分 | 赌局失去悬念 |
| 文明归属 | 是否全是同一个文化圈的案例 | 视野窄，容易被指出偏见 |

> **做法**：在 `SERIES.md` 里维护一张台账（§9），每集交付后回写一行。查重时看表，不靠记忆。

## 9. 系列台账模板（SERIES.md）

做系列时在项目根建这个文件。它是**唯一真相**——技能包里不存任何集的信息。

```markdown
# <系列名> 工作台账

## §一 交付台账

| 集 | 标题 | 变体 | 升维型 | 钩子类型 | 核心演示 | 状态 | 时长 |
|---|---|---|---|---|---|---|---|
| 01 | | | | | | 待做 | |

## §二 比分牌（有核心诘问时）

当前：A <x> : <y> B

## §三 钩子台账（查重依据）

| 集 | 开场第一句 | 结构类型 |
|---|---|---|

## §四 变体 / 升维型使用记录

| 集 | 变体 | 升维型 | 文明归属 |
|---|---|---|---|

## §五 待办与已知欠账
```

**回写纪律**：每集交付后 5 分钟内回写。**延迟回写等于没有台账**——
下一集查重时，你会凭记忆做判断，然后重复自己。
