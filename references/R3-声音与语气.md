# R3 · 声音与语气

> 这份文档解决两个问题：**声音怎么搭**、**话怎么说才不像上课**。
> 读它的时机：写脚本时、做音频之前。

---

## 5. 声音方案

### 5.1 三层声轨（垫乐必开）

| 层 | 音量 | 说明 |
|---|---|---|
| 人声 | +2dB | 主叙述，其余全部让路 |
| 音效层 | -18 ~ -24dB | 落位"叮"、压印"啪"、矛盾音"嗡—" |
| 垫乐层 | -26dB 以下（造物/升维段可至 -22dB） | 极简 pad + 低频脉动 |

**为什么必须有垫乐**：完全静音的段落会让手机扬声器听起来像"卡住了"，
观众会下意识检查网络。垫乐的作用是**证明片子还在走**，不是烘托情绪。

### 分幕垫乐性格

| 幕 | 垫乐 |
|---|---|
| 奇景 | 单音长混响 |
| 困局 | 低频脉动 60BPM |
| 动手 | 脉动提亮 |
| 造物 | 脉冲节拍 + 音效密集 |
| 穿透 | 退到 -30dB（让人声独占） |
| 升维 | 长混响单音 → **末句留白 1.5s 全静音** |
| 追问 | 一句 low pad，末尾静默 |

> **升维段的全静音是设计**：它是全片唯一一次"什么都不响"，
> 用听觉的空白把最后一句顶出来。不要怕"空"，怕的是每段都一样响。

### 5.5 片头「唰」飞入音效

片头标题卡入场配一记**飞入 whoosh**。

**要的是"唰"的一声，不是一段音乐。** 更"音乐化"的方案（钟琴 + 铺垫 / pad + bell）
已经被否过——因为观众需要的是"东西飞进来了"的物理感，不是氛围。

**合成配方（numpy，无版权风险）**：

- 粉噪（积分白噪）+ **对数高斯带通扫频**（FFT 分块滤波）
- **飞入**：180Hz→3600Hz 上扫 0.72s、0.045s 快起、到达前骤收（0.52s 起 3.0 幂衰减）
  + 58Hz 轻落点（0.70s）+ 空气尾
- **飞出**：3000Hz→220Hz 下扫 1.45s 缓降 + 0.55s 后一缕远端幽灵回声（-72% 增益）
- 落点：飞入 **0.12s**（标题卡入场）
- 混入音频构建脚本的 events 表，音量 **0.50**；母带归一化 -3dBFS

> **片尾 whoosh 默认不加**。原因很实际：它和旁白尾句几乎同时出现，
> 时机稍微没对准就变成"啪"的一声杂音。如果一定要加，先解决
> "音效起点 vs 旁白尾句"的可控对齐，再考虑。

### 5.5b 片头 BGM（第四层）

> **任务只有一个：在 0–1 秒把观众的耳朵按住。**
> 这 1 秒是整条片子注意力最贵的时段，而手机外放对低频几乎无感——
> 所以起音必须落在**中高频**。

| 项 | 规范 |
|---|---|
| 时长 | **0.0s 起，3.5s 淡完**（跨过片头 1.0s，托住第一句旁白，不在句中断掉） |
| 电平 | 0.0–1.0s：**-14 dB**（片头独占，可全开）；1.0–3.5s 线性降到 **-26 dB**（并入垫乐，不许盖旁白） |
| 起音 | **0.0–0.10s 内必须达峰**（attack 陡）。手机小喇叭只认瞬态，慢起等于没有 |
| 频段 | 主音在 **600–2000 Hz**；低频只做支撑（≤-18 dB），不承担抓耳任务 |
| 与 whoosh 的关系 | 两者**同时起**：BGM 负责"亮"，whoosh 负责"唰"。whoosh 音量 0.50 不变，BGM 不许压它 |
| 与垫乐的关系 | BGM 是独立第四层，**不与垫乐叠加计算电平**；3.5s 后完全并入垫乐音轨 |

**合成做法（numpy，零版权）**：两个短音 + 一声噪声刷。

1. 0.00s 一个 1320 Hz 正弦，衰减 0.35s（指数 4）
2. 0.06s 一个 880 Hz 正弦，衰减 0.55s
3. 0.00s 一段 0.12s 带通噪声（1.5k–6kHz）做"刷"的质感
4. 整体过一遍 3ms attack 包络防止爆音

**禁止**：用音乐库采样（版权）、用长混响 pad（拖慢节奏）、用低频下潜（手机听不见还占电平）。

**验收**：`ffmpeg -af "atrim=0:1,astats"` 看 **0–1s 的 RMS 必须高于 2–3s 段落至少 6 dB**——
证明这 1 秒真的比后面"响"，而不是一条平线。

### 5.2 声线

**默认：年轻、明快、有好奇心、不自居权威的男声**，语速 **1.12–1.18**。

**禁止**：播音腔、教学腔、过度煽情。
**幽默靠文本，不靠音色卖俏**——音色一"演"，可信度就掉。

> 声线可以按受众换（女声、少年声、方言），但三条不变：
> 语速别慢于 1.05、别用播音腔、别在一个系列里换人。

### 5.3 读音纪律

- **符号念意思**：不念"根号二"写成"√2"，而是念"根号二"；不念"π"，而是念"派"。
- **数字念中文**：年份念"一九二九年"，不念"nineteen twenty-nine"。
- **外来人名按主流译名**，第一次出现时补原文（一次就够，别反复念外文）。

## 5.4 幽默 8 法

| 编号 | 手法 | 例（抽象示意） |
|---|---|---|
| H1 | 拟人化 | 让一个抽象规则"开口说话" |
| H2 | 反差 | 庄重的场合说一句大白话 |
| H3 | 吐槽旁白 | 旁白对画面里的人表示不解 |
| H4 | 史料冷幽默 | 引一句当事人自己都没想到的话 |
| H5 | 悬念提问 | 故意问一个"你肯定答错"的问题 |
| H6 | 视觉梗 | 画面里放一个只有看到才懂的小细节 |
| H7 | 自嘲 | 承认"我小时候也以为……" |
| H8 | 反常识断言 | 一句话推翻观众的默认假设 |

### 入思三件套（每集都要有）

1. 一个**反直觉事实**
2. 一个**可迁移的思维动作**
3. 一个**留白问题**

### 反油腻四条

- 幽默 **≤4 处**。第 5 处开始，观众会觉得你在硬逗。
- **删掉信息量不减就删**。判断标准：删了这句，观众还懂吗？懂就删。
- **不许烂梗**。
- **不许拿真实人物的悲剧、疾病、死亡做段子**，也不许为了笑点牺牲事实。
- 每集必须有一个让观众"啊"一下的瞬间——**这个瞬间必须是事实本身带来的，不是段子带来的**。

## 6. 通俗化：翻译四步法（顺序不可反）

> **先有经验，才有名词。** 观众听不懂，几乎都是因为名词先来了。

### 四步

| 步 | 做什么 | 例（讲"复利"） |
|---|---|---|
| 1 | **身体锚** | "你借给朋友 100 块，他说一年后还你 110。" |
| 2 | **可数锚** | "第二年，他按 110 算利息，不是按 100。" |
| 3 | **图像锚** | 画一条越来越陡的曲线 |
| 4 | **名字锚** | "这个'利滚利'，学术上叫复利。" |

**先讲公式 `A = P(1+r)^n` 一律不合格**——那是把名字锚放在了第一位。

### 三条配套纪律

**术语准入**：

- 一集新术语 **≤3 个**
- 每个术语在本集出现 **≥2 次**
- 至少一次被**身体动作或图**演示过
- 至少一次被**翻译回大白话**

**两次讲述法**：人话版 → 换挡句"说人话就是……" → 精确版。

**复述测试**：写一句"这一集一句话版本"（≤25 字），**必须用不到任何术语**。
给一个没看过的人读，他能用自己的话复述 → 通过。

## 7. 真实性五道锁（QC-20）

| 锁 | 内容 |
|---|---|
| 一 | **句级 T 标**：T0 可验证事实（可算/可复现/可实验）／T1 共识事实（必写出处）／T2 有争议（必写"有争议"，不站队）／T3 传说（**配音与画面双标**） |
| 二 | **能算的必须算**：T0 断言在本地跑验算/复现，输出存档 `verify/` |
| 三 | **脚本两段式**：检索稿 → `FACTS.md` → 改写稿。**禁止一步成稿**（AI 会编造"他在想什么 / 器物什么颜色 / 谁说的"） |
| 四 | **AI 素材不得作为证据**：只当示意/气氛，披露写在发布文档 |
| 五 | **反方核对**（打假类选题）：列出反方最强论证，避免"用新神话反驳旧神话" |

**判停：任一条不过 → 不许进分镜。**

### 四级的处理要求

| 级 | 含义 | 处理 |
|---|---|---|
| **T0** | 可验证事实 | **必须本地验算/复现**，结果存 `verify/`，脚本可复跑 |
| **T1** | 共识事实 | 必须写出处；**≥2 个独立来源**（孤证降级并标注） |
| **T2** | 有争议 | 片中说"有争议"，**不站队、不点名**（点名等于贴标签） |
| **T3** | 传说 / 轶事 | **配音与画面双标**：旁白说"传说"，画面也要有视觉标记 |

## 8. 语气体检（QC-19）

交付前把这四条逐条问一遍：

1. **有没有一句话是"正确的废话"**（"这告诉我们坚持很重要"）？有就删。
2. **有没有一句在教观众做人**？有就改成陈述事实。
3. **有没有过度煽情**（形容词堆叠、排比、感叹号连用）？有就砍到一句。
4. **把旁白念出声**：像不像一个人在跟你讲一件他觉得有意思的事？
   像播报 / 像论文 / 像广告 → 重写。
