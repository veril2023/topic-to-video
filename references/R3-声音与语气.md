## 5. 声音方案（定稿）

### 5.1 三层声轨（垫乐必开）

| 层 | 音量 | 说明 |
|---|---|---|
| 人声 | +2dB | 主叙述 |
| 音效层 | -18 ~ -24dB | 落位"叮"、压印"啪"、矛盾音"嗡—" |
| 垫乐层 | -26dB 以下（造物/升维可至 -22dB） | 极简 pad + 低频脉动 |

**分幕垫乐**：奇景=单音长混响｜困局=低频脉动 60BPM｜动手=脉动提亮｜造物=脉冲节拍+音效密集｜穿透=退到 -30dB｜**升维=长混响单音 → 末句留白 1.5s 全静音**｜追问=一句 low pad 末尾静默。

### 5.5 首尾音效语言：「唰」飞入 / 飞出（ep01 第五轮定稿）

片头标题卡入场配一记**飞入 whoosh**。用户两次否决过更"音乐化"的方案（钟琴+铺垫 / pad+bell），
明确要的是"唰"的一声。**片尾 whoosh 已按用户要求删除**（2026-10-18："3分30秒片尾的声音就出现
了，这个声音很难控制"——与旁白尾句叠在一起时机难对准）；如未来再加片尾音效，必须先解决
"音效起点 vs 旁白尾句"的对齐可控性。

**合成配方**（numpy，无版权风险，`gen_bgm2.py` 留档）：
- 粉噪（积分白噪）+ **对数高斯带通扫频**（FFT 分块滤波）
- **飞入**：180Hz→3600Hz 上扫 0.72s、0.045s 快起、到达前骤收（0.52s 起 3.0 幂衰减）+ 58Hz 轻落点（0.70s）+ 空气尾
- **飞出**：3000Hz→220Hz 下扫 1.45s 缓降 + 0.55s 后一缕远端幽灵回声（-72% 增益）
- 落点：飞入 0.12s（标题卡入场）；**飞出已删**（见上）
- 混入 `build_audio{NN}.py` 的 events 表，音量 0.50；母带归一化 -3dBFS

### 5.5b 片头 BGM（v6 新增，用户 2026-10-19 要求）

> **任务只有一个：在 0–1 秒把观众的耳朵按住。** 这 1 秒是整条片子注意力最贵的时段，而手机外放对低频几乎无感——所以起音必须落在**中高频**。

| 项 | 规范 |
|---|---|
| 时长 | **0.0s 起，3.5s 淡完**（跨过片头 1.0s，托住第一句旁白，不在句中断掉） |
| 电平 | 0.0–1.0s：**-14 dB**（片头独占，可全开）；1.0–3.5s 线性降到 **-26 dB**（并入垫乐电平，不许盖旁白） |
| 起音 | **0.0–0.10s 内必须达峰**（attack 陡）。手机小喇叭只认瞬态，慢起等于没有 |
| 频段 | 主音在 **600–2000 Hz**；低频只做支撑（≤-18 dB），不承担抓耳任务 |
| 与 whoosh 的关系 | 两者**同时起**：BGM 负责"亮"，whoosh 负责"唰"。whoosh 音量 0.50 不变，BGM 不许压它 |
| 与垫乐的关系 | BGM 是独立第四层，**不与垫乐叠加计算电平**；3.5s 后完全并入垫乐音轨 |

**合成做法（numpy，零版权）**：两个短音 + 一声噪声刷。
① 0.00s 一个 1320 Hz 正弦，衰减 0.35s（指数 4）；② 0.06s 一个 880 Hz 正弦，衰减 0.55s；③ 0.00s 一段 0.12s 带通噪声（1.5k–6kHz）做"刷"的质感；④ 整体过一遍 3ms attack 包络防止爆音。
**禁止**：用音乐库采样（版权）、用长混响 pad（拖慢节奏）、用低频下潜（手机听不见还占电平）。

**验收**：`ffmpeg -af "atrim=0:1,astats"` 看 **0–1s 的 RMS 必须高于 2–3s 段落至少 6 dB**——证明这 1 秒真的比后面"响"，而不是一条平线。

### 5.2 声线

**年轻男声**（MiniMax `speech-2.8-hd` / `male-qn-jingying`），语速 **1.12–1.18**，明快、有好奇心、不自居权威。
**禁止**播音腔、教学腔、过度煽情；**幽默靠文本，不靠音色卖俏**。

### 5.3 读音纪律

公式念意思（"根号二"不念"√2"）；年份念中文（"一九二九年"）。

### 5.4 幽默 8 法（H1 拟人化｜H2 反差｜H3 吐槽旁白｜H4 史料冷幽默｜H5 悬念提问｜H6 视觉梗｜H7 自嘲｜H8 反常识断言）

**入思三件套**：① 一个反直觉事实 ② 一个可迁移的思维动作 ③ 一个留白问题。
**反油腻**：幽默 ≤4 处、删掉信息量不减就删、不许烂梗、**不许拿史实失真换笑点、不许拿数学人物的悲剧做段子**、每集必须有一个让观众"啊"一下的瞬间。

## 6. 通俗化：翻译四步法（顺序不可反）

> **先有经验，才有名词。** 听不懂数学，几乎都是因为名词先来了。

**身体锚 → 可数锚 → 图像锚 → 名字锚**
（ep07 复数：站起来向右转 90° → 转四次回到北 → 一个圆和一根箭头 → "数学家管这个动作叫虚数单位 i"。**先讲 i²=−1 一律不合格。**）

**术语准入**：一集新术语 ≤3 个；本集出现 ≥2 次；至少一次被身体动作或图演示；至少一次被翻译回大白话。
**两次讲述法**：人话版 → 换挡句"说人话就是……" → 精确版。
**复述测试**：写一句"这一集一句话版本"（≤25 字），**必须用不到任何术语**。

## 7. 真实性五道锁（QC-20）

| 锁 | 内容 |
|---|---|
| 一 | **句级 T 标**：T0 数学事实（必须验算）/ T1 共识史实（必写出处）/ T2 争议（必写"有争议"）/ T3 传说（**配音与画面双标**） |
| 二 | **能算的必须算**：T0 断言在本地跑验算，输出存档 `verify/` |
| 三 | **脚本两段式**：检索稿 → `FACTS.md` → 改写稿。**禁止一步成稿**（AI 会编造"他在想什么/器物什么颜色/谁说的") |
| 四 | **AI 素材不得作为证据**：只当示意/气氛，加角标 |
| 五 | **反方核对**（打假类）：列反方最强论证，避免用新神话反驳旧神话 |

**判停：任一条不过 → 不许进分镜。**
