# R10 · 适用边界：什么主题该接，什么该拒

> 这份文档的作用是**替用户做判断，也约束自己**。
> agent 最容易犯的错不是做得不好，是**什么都接**——然后交出一支根本不该做成
> 3 分钟竖屏视频的片子，用户花了半天到两天，拿到的东西没人看。

---

## 1. 一句话结论

这个技能只擅长一种东西：

> **有具体物、有反直觉点、有可查事实的「一件事」。**

它不是通用视频生成器，不是教程工具，不是情感内容工具，不是新闻评论工具。
**这四个"不是"必须主动告诉用户**，不要等他做完 8 集才发现。

---

## 2. 边界是机制决定的，不是偏好

四条硬约束直接推出四类禁区。理解了这个推导，遇到新题材也能自己判断。

| 硬约束 | 来源 | 推出的禁区 |
|---|---|---|
| 单集 3–4.5 分钟 | R2 时长纪律 | 装不下需要长铺垫的东西（完整理论、系统课程） |
| **兑现幕必须有画面自解释的演示** | 七幕结构第 4 幕（最长一幕） | 没有可画之物的题材（纯抽象、纯观点） |
| **前 8 秒零前置知识** | structures 不变量 #2 | 观众必须是"已经懂的人"的题材（专业课内容） |
| **关键事实需 ≥2 独立来源**（FACTS.md / QC-20） | 真实性红线 | 无定论、不可核实、刻意模糊的题材 |

> 第 2 条是最常被低估的。**"能画一张示意图"不等于"有兑现物"**。
> 兑现物的标准是：观众不看字幕、只听旁白也能看懂它在干什么。

---

## 3. 五级分类

### A 级 · 最顺（基本都能做，先往这里靠）

| 类型 | 例子 | 为什么顺 |
|---|---|---|
| 一个发明的诞生 | 某项技术最初是为了解决什么麻烦 | 麻烦 + 造物 + 画面，七幕直接成立 |
| 一个日常现象的反直觉解释 | 为什么井盖是圆的、天空为什么是蓝的 | 零前置 + 有反常识 + 有可视演示 |
| 一个概念的身世 | 零、负数、无穷、概率、复利 | 有历史人物 + 有争议 + 有具体符号 |
| 一个人的一个决定 | 某科学家在某次争论中的选择 | 有人、有代价、有赌注 |
| 一次失败 / 崩盘 | 理论被推翻、工程失败、公司倒下 | 天然有转折和"后人复盘"的落点 |

### B 级 · 能做，但必须挑角度

| 类型 | 必须满足 | 不满足会怎样 |
|---|---|---|
| 一本书的一个论点 | 只取一个点，**不是全书** | 变成读书笔记，完播率极低 |
| 一个学科 / 领域 | 必须找到**争论史主线**（R9 §3.5 法一） | 变成概念罗列 |
| 一个社会现象 | 必须有**可量化证据** | 变成观点输出，且容易被质疑 |
| 一个商业概念 | 必须有**具体案例** | 变成空话和管理学黑话 |

### C 级 · 很勉强（做出来大概率不好，要提前说清）

| 类型 | 为什么勉强 | 唯一出路 |
|---|---|---|
| 纯抽象理论（部分哲学、纯数学） | 没有可画之物 | 换成思想实验（R9 §3.6），文案容错率极低 |
| 需要 20 分钟才讲清的复杂机制 | 时长装不下 | 只取其中一个**反直觉的切片** |
| 情感 / 共鸣类（励志、治愈、感悟） | 本技能的调性是"理性 + 具体物"，情感类要另一套语言 | **本技能不做**，不要勉强 |
| 时事评论 | 3 分钟视频的寿命只有几天 | 改做图文，或找现象背后的长期机制 |

### D 级 · 直接拒（不是能力问题，是该不该做的问题）

| 类型 | 原因 |
|---|---|
| "揭秘""真相""被隐瞒的" 类 | 事实无法双源核实，且有误导风险 |
| 医疗 / 健康 / 用药建议 | 合规风险，且个体差异大 |
| 投资 / 理财 / 荐股建议 | 合规风险 |
| 政治敏感内容 | 合规风险 |
| 需要大量真实人物肖像的题材 | 肖像权 / 版权风险，本技能默认不用实景照片 |

## 4. 30 秒三问（唯一必须每次执行的判断）

用户说出主题后，**先不问细节，先过这三问**：

| # | 问题 | 过的标准 | 不过怎么办 |
|---|---|---|---|
| 1 | **能画出来吗？** | 这一集最核心的那件事，有一个具体的物/场景/动作能被画出来，且**不看字幕也能看懂** | 换角度，把抽象概念降到具体事件 |
| 2 | **能一句话说清它在争什么吗？** | 有一个二分问题，或一条会被验证的断言 | 说明它还不是"一件事"，只是"一个话题" |
| 3 | **事实查得到吗？** | 关键事实有 ≥2 个独立来源 | 拒，或降级成"这个问题目前没有定论"的元叙事 |

**三问全过 → 接。
一个不过 → 先尝试换角度（见 §6），换不出来再拒。
两个不过 → 直接拒，并说明原因。**

> 不要把三问变成 9 问。9 问（R1 §2）是**选题确定之后**逐条过的，
> 三问是**用户刚说出主题时**的第一道闸。用 9 问去筛主题会把用户问烦。

## 5. 拒绝话术（照着说，不要含糊其辞）

| 用户说 | 怎么回 | 建议替代 |
|---|---|---|
| 帮我做个励志视频 | 本技能的调性是"具体物 + 反直觉 + 可查证"，情感共鸣类需要另一套语言，我做出来会很像说教 | 找一个**具体的人做的一件具体的事**，用事实打动人 |
| 讲一下怎么用 Excel / 怎么健身 | 3 分钟竖屏装不下操作步骤，这类应该横屏 + 长视频 | 改成"一个操作背后为什么这样设计" |
| 做个今天的新闻解读 | 竖屏短视频的寿命只有几天，且事实还在变动 | 找这条新闻背后的**长期机制**，做成常青内容 |
| 讲一下养生 / 吃什么好 | 健康建议有合规风险，而且个体差异大，我不能替你给建议 | 改做"某个说法是怎么被验证/推翻的"（讲证据方法） |
| 帮我分析下这只股票 | 投资建议有合规风险 | 改做"这个行业是怎么赚钱的"（讲机制，不讲标的） |
| 讲一下哲学 | 大部分哲学命题没有可画之物，做成竖屏会变成满屏字 | 找一个**哲学家的一个具体争论**或**一个思想实验**（R9 §3.6） |

> **拒绝时必须给出替代方向**。只说"做不了"会让用户觉得是能力不足；
> 说清"为什么这类不适合这个媒介，但可以这样改"，才是专业判断。

---

## 6. 同一个主题，换个角度就能做

**"不能做"往往不是主题的问题，是**颗粒度**的问题。** 从"一个领域"降到"一件事"就成立了：

| ❌ 太粗（做不了） | ✅ 降到一个具体事件（能做） | 改了什么 |
|---|---|---|
| 讲讲量子力学 | 爱因斯坦和玻尔争了三十年，争的到底是什么 | 学科 → 一场争论 |
| 讲讲复利 | 一个国王答应按格子付米，付到第几格就付不起了 | 概念 → 一个具体情境 |
| 讲讲 AI 怎么工作 | 它认出了猫，但它说不出猫是什么 | 机制 → 一个反常现象 |
| 讲讲数学之美 | 一根两万年前的骨头上，为什么刻着三列划痕 | 主题 → 一个物件 |
| 讲讲经济学 | 一颗钻石和一杯水，哪个更值钱，为什么答案会反过来 | 学科 → 一个悖论 |

**改写的规律只有一条**：把"领域 / 概念 / 学科"降到**一个具体的人、物、事件、争论**。

---

## 7. 边界不是能力上限

C 级不是永远不能做，是**以本技能当前的结构和时长做不好**。三种可能的出路（都不在本技能范围内）：

| 出路 | 代价 |
|---|---|
| 换成思想实验结构 | 文案容错率极低，逻辑跳一步观众就掉队 |
| 换成长视频（10–20 分钟） | 整套时长纪律、钩子密度、字幕节奏全部要重写 |
| 换成图文 / 信息图 | 失去视频的沉浸感，但不依赖"可画之物" |

**本技能只覆盖竖屏 3–4.5 分钟这一种形态。** 超出这个形态的需求，
应当老实说明"这个工具不适用"，而不是硬做。

---

## 8. 一句话记住

> **能指着一个具体的东西说"你看这个"，就能做。**
> **只能指着一堆概念说"你理解一下"，就做不了。**
